# gongmun-writing-practice

서울특별시교육청 소속 교육공무직원·신규 공무원을 위한 실무 학습 도구 모음입니다. 정적 웹앱(바닐라 HTML/CSS/JS + Node 정적 서버)으로 만들어져 있어 별도 빌드 없이 바로 실행할 수 있습니다.

## 도구

### 공문서 작성 참고서 ([`공문서참고서/`](공문서참고서))

강의를 들은 뒤 업무 중 빠르게 찾아보는 참고서형 도구입니다. 검색창에 규정을 검색하면 근거·예시·팁이 그 자리에서 펼쳐지고, 완성한 기안문 전체를 붙여넣으면 A~E 27개 규정을 한 번에 규칙 기반으로 첨삭합니다.

- 근거: 「행정 업무의 운영 및 혁신에 관한 규정」(대통령령), 동 시행규칙(행정안전부령), 행정업무운영편람(2025), 「쉬운 공문서 쓰기 길잡이」(국립국어원, 2022)
- 실행: `공문서참고서_실행.cmd` 더블클릭 또는 `cd 공문서참고서 && npm start` (기본 포트 4174)
- 테스트: `cd 공문서참고서 && npm test`

### 공문서 작성 퀴즈 ([`공문서퀴즈/`](공문서퀴즈))

위 참고서의 A~E 규정 문항을 모아 랜덤 순서로 출제하는 자가 점검 퀴즈입니다(54문항, 매 회 새로 섞임).

- 실행: `공문서퀴즈_실행.cmd` 더블클릭 또는 `cd 공문서퀴즈 && npm start` (기본 포트 4175)
- 테스트: `cd 공문서퀴즈 && npm test`

### 복무·급여 도우미 ([`복무지침검색/`](복무지침검색))

교육공무직원의 병가 사용이 이번 달 세전 급여에 미치는 영향을 확인하는 계산 도구입니다.

- 실행: `복무급여도우미_실행.cmd` 더블클릭 또는 `cd 복무지침검색 && npm start` (기본 포트 4173)
- 테스트: `cd 복무지침검색 && npm test`
