# 2026 교육실무사 급여 프로필

- 프로필 ID: `SEOUL-2026-EDUCATION-PRACTICE-WORKER`
- 대표 유형: 월급제·상시근무
- 계산 범위: 세전 지급액
- 상태: 2026년 세전 급여 계산용 승인 완료
- 공식 급여 담당자 승인일: 2026-07-13

## 적용 전 확인

교육실무사는 임금지침상 공통임금체계 2유형 직종이다. 다만 직종명만으로 상시근무 여부를 확정하지 않고 실제 인사 직종명, 근무형태, 주당 소정근로시간과 수당 자격을 확인한다.

## 2026년 기본 구성

| 항목 | 금액 | 지급 주기 | 무급 병가 발생 시 |
|---|---:|---|---|
| 기본급 2유형 | 월 2,144,500원 | 매월 | 월 총일수 기준 일할계산 |
| 급식비 | 월 160,000원 | 매월 | 주 20시간 이상 대상, 일할계산 |
| 근속수당 | 월 41,000~984,000원 | 매월 | 인정 근속연수에 따라 산정 후 일할계산 |
| 가족수당 | 가족 구성에 따라 산정 | 매월 | 지급 자격 확인 후 일할계산 |
| 명절휴가비 | 연 2,144,500원 | 설·추석 각 1,072,250원 | 지급 기준 충족 시 전액 |
| 정기상여금 | 연 1,000,000원 | 1월·8월 각 500,000원 | 지급 기준 충족 시 전액 |

일반 교육실무사에는 별도 직종 관련 수당을 기본값으로 넣지 않는다. `교육실무사[전산]`은 통합직종 도입 전 채용 및 자격요건을 충족할 때 월 50,000원의 전산실무사 자격수당을 조건부로 추가한다.

## 근속수당

- 인정된 전임경력과 현 경력의 계속근로기간을 합산한다.
- 1년 이상부터 월 41,000원이며 1년마다 41,000원 증가한다.
- 24년 이상은 월 984,000원으로 동일하다.
- 경력증명서와 경력 산정 기준일을 확인한 뒤 확정한다.

## 가족수당

- 배우자: 월 40,000원
- 직계존속: 1명당 월 20,000원
- 첫째 자녀: 월 50,000원
- 둘째 자녀: 월 80,000원
- 셋째 이후 자녀: 1명당 월 120,000원
- 부양가족 요건, 공무원 지급 기준 준용 사항과 중복수급 여부를 확인한다.

## 병가 계산 순서

1. 해당 회계연도의 누적 병가 중 유급 범위와 무급 병가일수를 확정한다.
2. 기본급·급식비·근속수당·가족수당을 각각 `ceil(월액 × (월 총일수 - 무급일수) ÷ 월 총일수)`로 계산한다.
3. 항목별 원 단위에서 올림한다.
4. 명절휴가비·정기상여금은 지급 기준일의 자격 충족 여부를 확인해 전액을 별도로 합산한다.
5. 항목별 계산액을 합산하여 세전 지급액을 산출한다.

### 검증 예시

31일인 달에 무급 병가 1일, 인정 근속수당과 가족수당이 없는 경우:

```text
기본급  ceil(2,144,500 × 30 ÷ 31) = 2,075,323원
급식비  ceil(160,000 × 30 ÷ 31) = 154,839원
세전 지급액 = 2,230,162원
```

## 근거 위치

- 월급제 적용 기준과 기본급 유형: 임금지침 표시 21~23쪽
- 근속수당: 표시 24쪽, 31쪽
- 가족수당: 표시 32쪽
- 명절휴가비: 표시 33쪽
- 정기상여금: 표시 34쪽
- 직종별 임금 기준: 표시 35쪽
- 급식비 및 교육실무사[전산] 자격수당: 표시 37쪽
- 복무 사용 시 일할계산: 표시 57~58쪽

## 승인 시 확인한 항목

- 인사시스템의 정확한 직종 코드와 실제 근무형태
- 인정 근속연수 및 가족수당 자격
- 교육실무사[전산] 해당 여부와 자격수당 조건
- 명절휴가비·정기상여금 지급 기준일의 재직·계속근로 요건
- 같은 달에 다른 무급 사유가 함께 발생한 경우의 통합 공제일수
