## 방학 중 비근무 안전 규칙

- 연간근무일수와 학교 학사일정을 실제 입력값으로 받는다.
- 방학 중 비근무기간 전체를 무급 병가로 간주하지 않는다.
- 방학 월에 실제 무급 병가가 발생한 경우 기본급·급식비·특수교육지원수당은 전체 공제일수로 계산한다.
- 근속수당과 가족수당은 방학기간을 제외한 공제일수만 반영한다.
- 방학 전후 병가는 방학기간으로 단절되므로 원칙적으로 연속 병가로 보지 않는다.

## 병가 계산식

```text
기본급·급식비·특수교육지원수당 =
  각 항목 × (월 총일수 - 전체 공제일수) ÷ 월 총일수

근속수당·가족수당 =
  각 항목 × (월 총일수 - 방학기간을 제외한 공제일수) ÷ 월 총일수
```

각 항목은 원 단위에서 절상한다.

## 검산 예시

### 31일 월, 방학 외 무급 병가 1일, 근속·가족수당 없음

```text
기본급: 2,075,323원

```

- 직종별 근무형태와 특수교육지원수당: 표시 35쪽·37쪽
