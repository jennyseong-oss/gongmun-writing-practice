## 공통 안전 상태

- 공식 문서 기반 계산식 구조화: 완료
- 세전 지급액 범위 설정: 완료
- 세금·4대보험·실수령액 제외: 완료
- 앱 공개 계산 활성화: 아직 금지
- 실제 급여대장·계약 사례와의 대조: 필요

## 다음 개발 단계

1. 여섯 프로필의 입력 질문을 공통·직종별로 정리한다.
2. 사용자가 입력한 조건을 프로필과 규칙에 매칭하는 결정 트리를 만든다.
3. 계산 결과에 근거·계산식·검토 경고를 표시하는 응답 스키마를 만든다.
4. 검증 사례를 자동 실행하는 테스트 러너를 구현한다.
5. 급여담당자의 수기 결과와 비교한 뒤 공개 계산을 활성화한다.

다음 산출물은 `병가 급여 계산 입력 질문 및 결정 트리`가 적합하다.
