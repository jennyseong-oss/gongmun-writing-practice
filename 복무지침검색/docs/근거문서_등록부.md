1. 답변에는 문서 ID, 문서명, 쪽, 항목명, 기준일을 표시한다.
2. 계산 규칙은 `사용승인` 상태의 근거만 실행한다.
3. FAQ는 지침 해석을 돕는 보조자료이며 법령·협약·취업규칙·지침을 대체하지 않는다.
