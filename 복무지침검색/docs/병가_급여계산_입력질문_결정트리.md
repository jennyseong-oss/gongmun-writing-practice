# 병가 세전 급여 계산 입력 질문 및 결정 트리

## 사용자에게 묻는 순서

### 1. 기본 프로필

1. 직종 또는 계산 유형은 무엇인가요?
2. 월급제·시급제·일급제·호봉제 중 어느 유형인가요?
3. 무기계약·기간제·단시간·초단시간 중 어디에 해당하나요?
4. 상시근무·연간근무일수제·방학 중 비근무 중 어디에 해당하나요?

직종 선택 결과와 실제 계약조건이 다르면 계약조건을 우선하고 담당자 확인 경고를 표시한다.

### 2. 계약과 근로시간

1. 입사일과 계약 종료일은 언제인가요?
2. 주 소정근로시간과 1일 소정근로시간은 몇 시간인가요?
3. 계산 대상 월의 총일수는 며칠인가요?
4. 방학 중 비근무자라면 해당 월 방학일수와 지정 근무일은 며칠인가요?

### 3. 병가

1. 계산 대상 회계연도에 이미 사용한 병가는 총 며칠·몇 시간인가요?
2. 그중 유급 병가는 며칠·몇 시간인가요?
3. 이번에 사용할 병가는 며칠·몇 시간인가요?
4. 일반 병가인가요, 업무상 재해에 따른 병가인가요?
5. 진단서 제출 대상이며 제출했나요?

### 4. 급여항목

1. 월 기본급 또는 시급은 얼마인가요?
2. 근속수당 지급액은 얼마인가요?
3. 가족수당 지급액은 얼마인가요?
4. 직종·자격수당 중 실제 지급 중인 항목은 무엇인가요?
5. 계산 대상 월이 명절휴가비 또는 정기상여금 지급월인가요?
6. 해당 지급기준을 충족하나요?

앱에 저장된 표준금액과 사용자가 입력한 급여명세 금액이 다르면 자동으로 덮어쓰지 않고 차이를 표시한다.

## 결정 흐름

```text
프로필 선택
  → 실제 계약조건 확인
  → 병가 적용 제외 여부 확인
  → 병가 총일수·유급일수 산정
  → 이번 병가의 유급·무급 구간 분리
  → 방학 중 비근무 예외 확인
  → 실제 지급 수당 확인
  → 항목별 일할/전액/제외 분류
  → 세전 지급액 계산
  → 근거·계산식·경고 표시
```

## 자동 중단 조건

- 급여체계가 확인되지 않음
- 초단시간 여부가 불명확함
- 기간제 계속근로기간을 계산할 수 없음
- 누적 병가 사용량을 알 수 없음
- 방학 중 비근무자인데 학사일정이 없음
- 직종수당 자격이 불명확함
- 공식 지침 금액과 실제 명세 금액이 다르지만 사유를 확인하지 못함
- 업무상 병가인데 산재 승인·휴업급여 정보가 없음

중단 시 금액 대신 `담당자 검토 필요`와 확인할 질문을 반환한다.

## 결과 화면 필수 표시

- 적용 프로필과 실제 계약조건
- 유급 병가와 무급 병가 구분
- 급여 항목별 기준액·계산식·지급액
- 세전 합계
- 제외 항목: 세금·4대보험·실수령액
- 근거 문서·표시 쪽·기준연도
- 검증 상태와 담당자 확인 항목
